Vanta Forge

A fictional experimental engineering studio where force, precision, and visual aggression become the brand language.

IdentityBrutalist / industrial / kinetic
PaletteVermilion, coal, chrome
Primary behaviorTest the machine

Concept & process

Vanta rejects polished technology minimalism. The composition behaves like a pressure event: type collides with an impossible machine, data is blunt, and navigation feels stamped into the chassis. Archivo Black, hard borders, and compressed vertical rhythm establish an identity unlike the rest of the collection.

Technique & implementation

A Codex-generated chrome mechanism is composited into a skewed architectural crop. CSS blend modes create reactive cyan opposition over red. A custom cursor, horizontally drifting machinery, kinetic ticker, system rows, and a pointer-driven pressure gauge provide the physical response.

Blend-mode typeCustom cursorPointer gaugeKinetic tickerBrutalist grid

Three passes

01 / Composition & art direction

Increased calibrated tension

  • Rebalanced the headline collision against the machine crop and preserved the chrome focal point.
  • Added a five-vw calibration grid and vertical 44–B load-test marking.
  • Separated measurement typography, calls to action, and system inventory into a rigorous hierarchy.
02 / Motion & interaction

Made force tangible

  • Added a responsive cursor, pointer-drift image movement, endless object/force ticker, and fast row impacts.
  • Built a live pressure gauge with a rotating needle and numeric MPa feedback.
  • Used skewed section entrances with shorter timing than the other sites to preserve aggression.
03 / Polish & technical quality

Contained the machine

  • Corrected a ten-pixel mobile overflow caused by the full-bleed chassis edge.
  • Added minimum touch sizes, keyboard focus rings, and reduced-motion fallbacks.
  • Verified all imagery, interactions, and internal links at desktop and 390px mobile widths.

Tools

Codex image generation, semantic HTML, CSS blend/compositing, Pointer Events, IntersectionObserver, and compact vanilla JavaScript. The result has no framework or runtime dependency.
