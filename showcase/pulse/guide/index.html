Signal notes / Experience 04

Synesthesia FM

A playable chromatic broadcast that turns pointer movement, keyboard input, and sound into a field of luminous color.

IdentityElectric / nocturnal / synesthetic
PaletteBlack, acid lime, full spectrum
Primary behaviorPaint sound

Concept & process

The site is designed as an instrument rather than a campaign page. A radio-frequency fiction gives structure to an otherwise abstract experience: start a carrier signal, enter the canvas, choose a transmission, and alter color decay.

Technique & implementation

An original liquid-spectrum image provides the launch state. The instrument itself is code-native: Canvas 2D renders additive radial fields under the pointer, hue and decay controls mutate the renderer, and a quiet Web Audio sine carrier is created only after direct user input.

Three passes

01 / Composition & art direction

Separated signal from spectacle

  • Reframed the hero artwork as an irregular spectral membrane instead of a conventional image circle.
  • Built a bold filled/outline type rhythm and added a compact signal-stability readout.
  • Used radio metadata and frequency numerals to make the palette feel functional.
02 / Motion & interaction

Turned the page into an instrument

  • Built a pressure-like color painter whose particles bloom, drift, mix, and decay.
  • Added track-to-hue switching, a voluntary audio carrier, and scale-based section entrances.
  • Added keyboard painting to preserve the generative interaction beyond pointer users.
03 / Polish & technical quality

Controlled the energy

  • Reworked hero geometry and control stacks for narrow screens.
  • Added focus indicators, 44px controls, optional sound, and reduced-motion handling.
  • Verified the canvas, sliders, transmission buttons, local navigation, and zero-overflow state.

Tools

Codex image generation, Canvas 2D, Web Audio, Pointer Events, accessible range inputs, CSS compositing, and vanilla JavaScript. Audio is off by default and no media file is downloaded.
